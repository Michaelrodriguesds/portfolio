## 👨‍💻 Sobre

Este projeto reúne aplicações e sistemas desenvolvidos para demonstrar experiência prática em desenvolvimento **web, mobile, APIs, bancos de dados, tempo real e deploy**.

Meu foco é transformar problemas e ideias em soluções funcionais, com interfaces responsivas e uma estrutura que possa evoluir conforme a necessidade do projeto.

Também utilizo ferramentas de **IA como apoio ao desenvolvimento**, especialmente para pesquisa, geração de alternativas, implementação e depuração. O código é estudado, adaptado e testado dentro do contexto de cada projeto.

## 🚀 Principais projetos

### 📅 Glamour Agenda
Aplicação para gestão e agendamento de salão de beleza, com calendário, clientes, serviços, controle financeiro, dashboard e integração com API REST.

**Tecnologias:** Flutter · Dart · API REST

### 📦 Controle de Estoque
Sistema web para gerenciamento de produtos, estoque e informações de operação, com dashboard e persistência de dados.

**Tecnologias:** Angular · .NET · MongoDB · Docker

### 💬 Mural Social PHP
Aplicação web com publicação de mensagens, persistência em banco de dados, validação e cuidados contra SQL Injection e XSS.

**Tecnologias:** PHP · MySQL · PDO · JavaScript · CSS

### 🎮 Snake Game Multiplayer
Jogo multiplayer em tempo real com comunicação via WebSocket, bots, chat e Canvas API.

**Tecnologias:** Node.js · Express · WebSocket · JavaScript · Canvas API

## 🧰 Tecnologias e conhecimentos

- **Front-end:** HTML, CSS, JavaScript, TypeScript, React, Angular
- **Back-end:** Node.js, .NET, PHP, Python
- **Mobile:** Flutter, Dart
- **Banco de dados:** MongoDB, MySQL, SQL
- **APIs:** REST e integração entre aplicações
- **Tempo real:** WebSocket
- **DevOps / Deploy:** Docker e serviços de hospedagem em cloud
- **UI/UX:** interfaces responsivas e experiência do usuário
